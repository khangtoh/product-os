# PocketGarden

A small web app for saving articles you want to read and finding them again later.

## What it does

- Save an article by URL, with its title.
- Search your saved collection by title.
- Open a saved article at its original URL.

## Running it

Open `src/index.html` in a browser. There is no build step and no server yet.

## Status

Early prototype. No analytics, no accounts, no deployment pipeline.
