# ProductOS instance: PocketGarden

The shared product memory where humans and AI steer, build, operate, and evolve this product together.

Template version: 0.2.0. Adoption date: 2026-09-27. Project owner: the product owner, recorded as `product-owner` — a role identifier, since no name or handle was supplied. See [STATE.md](STATE.md).

The **initial brief is complete** as of 2026-09-27. Several product questions remain deliberately open or deferred; a complete brief is not the same as a validated product.

## Start here

- Read [../PRODUCT.md](../PRODUCT.md) — the canonical contract at the project root — for product intent, and [STATE.md](STATE.md) for current work.
- Agents also read [AGENTS.md](AGENTS.md). Humans can use [WORKING_TOGETHER.md](WORKING_TOGETHER.md).
- Use [guided onboarding](ONBOARDING.md) to orient a new contributor or resume the incomplete checkpoint. It does not reset the established brief.
- Use [execution](EXECUTION.md) to carry out the next bounded action and leave a resumable handoff.
- The root [../AGENTS.md](../AGENTS.md) already points here under "Product context".
