# Vision

Updated: 2026-09-27 — established during ProductOS adoption.

## Durable ambition

A researcher should be able to retrieve something they saved while reading **without having to organize everything**.

The lasting change is the removal of the filing tax. Existing tools ask the person to invest effort at save time — choose a folder, apply tags, write a note — so that retrieval works later. PocketGarden's ambition is that saving stays effortless and retrieval still succeeds.

Source of direction: the product owner, stated 2026-09-27 during onboarding. The audience (researchers who lose track of what they saved) and the problem are an **explicit untested hypothesis**; the owner asked that they be treated that way. No user research supports them yet.

## Principles and boundaries

Durable principles, derived from the ambition above:

- **Saving costs nothing.** Any feature that requires the user to organize, categorize, or file at save time works against the reason this product exists.
- **Retrieval works from partial memory.** The user will remember something vague about what they saved, not where they put it.
- **Privacy by construction.** The project forbids analytics, telemetry, and third-party scripts ([AGENTS.md](../AGENTS.md)). This is treated as a product boundary, not only an engineering one — it shapes how success can be measured.

Unacceptable tradeoffs and strategic boundaries beyond these are **not yet established**; the interview has not reached non-goals. Product identity stays canonical in [../PRODUCT.md](../PRODUCT.md).
