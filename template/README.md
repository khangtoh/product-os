# Bare project template

Copy only [product/](product/README.md) into the target project. That directory is self-contained: its internal links do not depend on the guides or examples elsewhere in this repository.

It includes product context, operating conventions, and blank record templates. It contains no live outcomes, decisions, evidence, cycles, or inherited authority. Record directories are created with their first actual record.

See [quickstart](../docs/QUICKSTART.md) for installation, agent-context wiring, and first-use steps. Do not copy an applied project's history as a shortcut to adoption.
